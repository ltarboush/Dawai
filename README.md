# Dawa'i | دوائي

Interactive concept prototype for a smart medication pickup kiosk and pharmacist release workflow.

## Features
- Pharmacist portal with order queue and release checklist
- Smart locker state simulation
- Patient app flow with token/QR pickup experience
- Arabic/English interface toggle
- 3D cabinet mockup with interactive viewing angles

## Run locally
Open the project in a browser directly:

```bash
cd /workspaces/Dawai
python3 -m http.server 8000
```

Then visit:

http://localhost:8000/
